# About

Slay the Spire 2 Wiki is an independent community reference built for quick run planning and detailed game lookup.

Structured game data and original character combat-model artwork are sourced from [Spire Codex](https://spire-codex.com/docs). Source attribution remains attached to generated content, and data is regenerated when upstream information changes.

This project is open source. Corrections and contributions can be submitted through the [GitHub repository](https://github.com/funkchi/wiki.sts2.app).

The wiki is not affiliated with, endorsed by, or sponsored by Mega Crit.
