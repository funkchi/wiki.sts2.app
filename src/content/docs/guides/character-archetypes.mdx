# Character Archetypes

Archetypes are recognition tools, not drafting instructions. Start from the cards and relics already present, then identify the shortest path to a reliable engine.

## Ironclad

Ironclad can turn cards, health, Strength, and Block into long-term resources. Exhaust packages are strongest when they provide energy efficiency, draw, and defense together.

## Silent

Silent often wins by converting card flow into precise offense through Poison, Shivs, discard interactions, and Sly cards.

## Defect

Defect's Orb system rewards both output per Orb and control over which Orb acts. Focus, capacity, generation, and evoke speed need to support the same plan.

## Necrobinder

Necrobinder combines Osty, discard-pile access, Replay, Retain, Ethereal cards, and attack amplification.

## Regent

Regent can build around Stars, created cards, Forge interactions, and concentrated cosmic payoffs.
