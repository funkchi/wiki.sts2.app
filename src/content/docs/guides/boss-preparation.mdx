---
title: Boss Preparation Guide
description: Prepare for Slay the Spire 2 bosses by reading attack patterns, testing deck speed, defense, scaling, and using the remaining map deliberately.
---

Boss preparation starts when the boss is revealed, not at the final rest site. The visible opponent turns every card reward, shop, upgrade, and risky path into a more specific decision.

## Translate a Pattern Into Tests

Look for opening pressure, large turns, repeated pressure, multiple targets, debuffs, phase changes, and long clocks. Then write the weakest answer in plain language.

## Measure Setup Speed

Count the energy and cards needed before the deck reaches normal output. Expensive setup can dominate turn six and still lose too much health on turns one through three.

## Spend the Remaining Map

Take cards, shops, rest sites, and optional fights only in relation to the identified boss test. Saving resources has little value if the run cannot pass the next required check.

## Final Rest-Site Checklist

Before committing to the boss, identify the most dangerous turn, the cards that answer it, setup time, long-fight scaling, add handling, and potion assignments.
