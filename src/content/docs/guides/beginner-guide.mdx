# Beginner Guide

The first goal of a run is not to assemble a perfect archetype. It is to solve the next few fights without filling the deck with cards that stop working later.

## Read the Run in Layers

At the start of each floor, ask what can hurt you before the next rest site, what the act boss tests, and which resource you are spending. Health, gold, potions, and card rewards are connected.

## Take Cards for Jobs

Every card should have a job: efficient damage, front-loaded defense, multi-target pressure, consistency, scaling, or coverage. If you cannot name the turn on which you want to draw a reward, skipping is often better.

## Keep the Deck Coherent

Adding cards is only half of deckbuilding. Removals and skips increase the chance of drawing your best cards. Balance energy as well as card count so the deck can act on bad hands, not only ideal ones.
